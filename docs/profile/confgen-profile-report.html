What changed

The cached confgen importer reads the workbook relationship map, selected worksheet XML, and shared strings directly from the ZIP archive. It supports sparse and empty rows, rich and inline strings, formulas, entities, namespaces, and Excel character escapes. Inputs with unsupported XML constructs or worksheet entries above 512 MB fall back to Excelize.

Why the Canvas source does not open as a webpage

The editable .canvas.tsx file imports cursor/canvas, a virtual runtime supplied by Codex. A normal browser cannot resolve or compile it. This HTML file is the standalone, dependency-free browser export. Open it directly, or serve this directory with python -m http.server 8000 --directory .\docs\profile and visit localhost:8000/confgen-profile-report.html.
